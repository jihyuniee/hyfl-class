# 입시 자료 질문 기능

`/admissions#ask` → `/api/admissions/ask` → 출처가 있는 등록 자료 검색 → OpenAI Responses API → 답변과 출처 링크.

- 서버 전용 `OPENAI_API_KEY` 필요. 기본 모델 `gpt-4.1-mini`, 선택적으로 `OPENAI_ADMISSIONS_MODEL` 설정.
- `records.json` 중 기존 화면의 검증 필터를 통과한 수시 전형만 사용. 정시 결과·반영계획과 학과 탐색 목록도 포함한다. 학과 목록은 참고 자료이며 공식 확정 목록이 아니라는 표시를 유지한다.
- 키·학생 개인정보·대화기록을 저장하거나 로그로 출력하지 않는다. OpenAI 요청은 `store: false`를 사용한다. 제공자 자체 데이터 보관 정책과 별개다.
- 검색 근거에 존재하는 ID만 출처로 허용한다. JSON 응답이 잘리거나 출처가 유효하지 않으면 오류로 안내한다. 답변 내용의 사실성까지 프로그램으로 보증하는 것은 아니므로 최종 모집요강 확인 안내를 표시한다.
- 입력 500자, 출력 1200토큰, API 대기 45초. IP 해시 기준 인스턴스당 시간당 20회, 전체 인스턴스당 하루 200회 제한. 서버리스 인스턴스가 늘거나 재시작하면 제한이 초기화되므로 전역 비용 한도가 아니다. 운영상 더 엄격한 제한이 필요하면 공유 저장소 기반 카운터 또는 플랫폼 방화벽 제한을 추가한다.
- 실시간 웹 검색, 합격확률 판정, 개인 상담기록 검색은 하지 않는다. 등록된 자료에 지원자격이 없으면 확인되지 않는다고 답하도록 지시한다.

검증: `npm test`, 변경 파일 ESLint, `npx tsc --noEmit`, `npm run build`. 로컬 빌드의 기존 Supabase 공개 환경변수는 테스트용 자리표시자로 제공했다. 실제 OpenAI 호출은 Vercel 배포 후 확인하며 키를 내려받지 않는다.
