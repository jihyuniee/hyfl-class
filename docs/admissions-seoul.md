# 서울 주요대학 참고자료 (2026-10-28)

- 학생 경로: `/admissions/seoul`. 기존 입시 홈과 내비게이션에서 연결한다.
- 인문·사회·어문 중심, 서울 소재 모집단위만 선별한다. 대학 전체 학과나 서울 소재 대학 전체를 망라하지 않는다.
- `public/admissions-seoul/plans.json`: 2028 시행계획 15개 대학, 30개 반영 사례. 행 형식은 `[학년도, 대학, 전형, 대상, 국어%, 수학%, 영어%, 탐구%, 상세배점, 수능%, 기타평가, 활용지표, 영어, 유의사항, 원문쪽, 원문URL]`. null은 별도 산식/미기재이며 0이 아니다. Google Drive 링크는 검토한 시행계획 사본이다.
- `results.json` / UTF-8 BOM `results.csv`: 11개 대학 292개 학과·연도 기록. 2024~2026 결과를 포함하나 대학별 최신 연도는 다르다. 원문의 결과 학년도와 어디가 화면의 평가기준 학년도를 구분한다.
- 최초 상담표의 국민·서강·서울여·성신·숙명·숭실·한국외대 서울 240개 기록에, 어디가의 서울대 11·고려대 11·한양대 16·연세대 14개 2024 일반전형 결과를 추가했다. 새 자료 52개는 각 대학 어디가 2025 평가기준 화면에서 확인했다. `results.json`의 source/source_note를 유지한다.
- 연세대의 ‘영역별 70% cut’ 아래 평균은 종합 컷과 혼동할 수 있어 환산점수만 표시한다. 2025 어디가의 개별 과목 백분위 컷을 평균 내어 종합 70% 컷으로 만들지 않는다.
- 숭실대는 공식 2026 통계의 등록자 평균 백분위와 70% 컷을 별개로 표시한다. 2024/25는 해당 PDF의 추이표 평균만 기재했다.
- 대학 환산점수를 만점으로 나눠 ‘평균 백분위’로 표시하지 않는다. 백분위의 산식도 대학별로 다를 수 있으므로 대학 서열/자동 합격 예측에 쓰지 않는다.
- `counseling-2028.xlsx`: 상담용 산출물 사본. 빈 상담표, 15개 대학 2028 반영방식, 11개 대학 292개 입결, 교사용 읽는 법을 수록한다. 기존 상담표의 수식과 서식은 보존하고 입결 52개를 추가했다. 학생 개인 정보는 없다.
- 2028의 내신 5등급제와 과거 내신 9등급제, 개편 수능과 과거 수능을 그대로 대응시키지 않는다. 시행계획은 최종 모집요강과 대조해야 한다.
- 실제 등록자 입결과 기존 이투스 지원참고표를 별도로 표시한다. 과거 컷으로 합격 확률을 계산하지 않는다.
- 2026-10-30: 페이지 상단에 표준점수·백분위 과목별 입력과 합계·평균 직접 입력을 제공한다. 지원참고표 502건에 기존 `/admissions`의 상향·소신·가능·적정·안정 분류 간격을 적용한다. 이 구간은 앱의 점수 차이 규칙이며 대학·이투스의 공식 판정 기준이 아니다. 원본 시험정보와 현재 고2 적용성 미확인 안내를 보존한다.
- 분류: 표점합·백분위합(평균×3)이 모두 기준 이상이면 최소 여유 15점 이상 안정, 5점 이상 적정, 나머지는 가능. 기준 미달은 부족분이 표점합 4·백분위합 3 이내면 소신, 표점합 12·백분위합 9 이내면 상향. 둘 중 하나라도 상향 범위를 초과하면 제외한다. 영어는 선택 입력이며 분류에는 반영하지 않는다.
- 각 구간에서 기존 주요 서울 대학 탐색 순서와 대학 내 참고점수 내림차순을 유지한다. 카드에는 두 참고점수·입력값과의 차이·부족분·2028 반영방식 원문을 표시한다. 점수는 브라우저 상태에만 보관한다.
