# 서울 소재 대학 전체 탐색 — 2026-11-06

- 사용자 요청: 모의고사 상향·소신·적정 메뉴 재검토, 서울 소재 전체 대학으로 범위 확대. 기존의 확인된 사실만 사용한다는 조건을 유지한다.
- 커리어넷 학교정보에서 `대학교 → 서울특별시 → 대학(4년제)`를 조회하고 30개씩 세 페이지의 61개 캠퍼스 기록을 전부 확인했다. 56개 학교로 묶고, KCI의 육군사관학교 화랑대연구소 소재지 및 교육청 대학 안내로 서울 소재 육군사관학교를 추가했다. 57개 학교는 일반·교육대학 42, 사이버·방송통신 12, 기타·별도선발 3으로 나눴다.
- 원문 URL: https://www.career.go.kr/cloud/w/school/list . 필터가 URL에 보존되지 않으므로 조회 조건·원문 61행·학교별 출처/확인일을 `public/admissions-explorer/seoul-universities.json`에 기록한다. 육사 소재지 출처는 해당 레코드에 별도 기재한다.
- 전체 목록은 학교 소재지·유형의 탐색 범위다. 2028 모집 확정이나 합격 가능성을 검증한 목록이 아니다. 가톨릭대·경기대는 서울 캠퍼스로 별도 식별하고, 부천·수원 등 다른 캠퍼스 요약을 자동 연결하지 않는다. 기술대학·원격대학·사관학교 등은 일반 정시 모집과 구분한다.
- 홈·모의고사·정시·수시 대학 선택을 전체 목록으로 연결한다. 정시에는 학교 검색, 유형 선택, 자료 수록 상태, 대학 홈페이지·소재지 근거를 제공한다. 수시 전체 조회에 비서울 대학 기록이 섞이지 않도록 목록 범위를 적용한다.
- 기존 502개 지원참고표의 적용 시험/학년과 앱 자체 점수차 5·15점, 표점4·백분위합3점 등의 구간은 2028의 검증된 합격 판정 기준이 아니다. 이를 복구하지 않고 점수 제출 결과에 `상향·소신·적정 판정: 자료 미확보`를 명시한다. 모의고사 난도 보정이나 판정 수치를 새로 만들지 않았다.
- 미완료: 실제 상향·소신·적정 판정 연결. 해당 시험 연월·학년·2028 적용 여부·기관·기준일·대학/학과별 산식 또는 원 판정이 확인된 유니브/배치자료가 필요하다. 프로그램 접속·연동·예측 정확도 검증은 수행하지 않았다.
