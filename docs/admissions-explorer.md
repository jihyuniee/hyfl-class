# 입시 홈 수시·정시 분리 (2026-10-29)

## 학생 화면

- `/admissions` 기본 진입을 `overview`로 변경. 정시·수시 카드와 기존 도구 링크를 제공한다. 기존 `#score`, `#search`, `#plan`, `#minimum`, `#resources` 등은 유지한다.
- `/admissions/seoul`: 기존 11개 대학 292개 정시 결과와 15개 대학 반영 사례를 보존한다. 실제 입결을 먼저 배치하고 지원참고 예상점수 표는 별도 버튼으로 불러온다. 학교 선택은 30개 대학으로 확장하되 실제 입결 미수록과 반영 사례 미수록을 구분한다. 예측값을 합격 컷으로 바꾸지 않는다.
- `/admissions/susi`: 30개 대학 학과·모집단위 탐색, 10개 전공 분야의 공부·탐구 안내, 학교·계열별 전형 후보를 연결한다. 대학 선택 URL 쿼리를 지원한다.
- `/admissions/china`: 공통 지원 순서, 칭화대·푸단대·저장대 공식 안내, 학교장 추천 안내를 제공한다.

## 자료의 의미와 제한

- `directory.json`: 기존 이투스 지원참고표에서 서울 지역·비서울 캠퍼스 표기 없는 인문 및 공통 자유전공 명칭을 선별한 472개 탐색 목록. 2028 수시 모집단위 확정표가 아니다. 전공별 모집 여부·모집인원·추천 및 고교유형 지원자격을 원문 확인하도록 명시한다.
- `reference.json`: 같은 원본에서 해당 명칭의 전형별 지원참고 점수 502개. 표점합과 백분위 합을 원문 값으로 보존하고, 백분위 표시만 기존 앱과 동일하게 합÷3으로 산출한다. 실제 입결로 합치지 않는다.
- `majors.json`: 학부 공식 교육과정과 학과 소개를 참고한 10개 분야. 구체적 원문 URL·참고 대학·학과·확인일을 보존한다. 고교 교과 연결, 역량, 탐구 질문·방법은 편집한 학급 안내 제안이며 대학의 필수·권장 과목이나 합격 조건으로 표시하지 않는다. 예시 대학과 선택 대학이 다를 수 있음을 명시한다.
- 수시 전형은 기존 검토 데이터에서 학교·계열·조건으로 선별한 후보이다. 특정 학과의 해당 전형 모집을 확정하지 않는다. 한국외대 서울/글로벌 공통 표기는 서울 탐색에서 연결하되, 캠퍼스별 최저를 보존하고 글로벌 단독 대학과 합치지 않는다. 인문 탐색에 과학·SW·의학 전형을 자동 연결하지 않는다.
- 중국 대학: 칭화대는 현재 공식 2027 자격·서류 List.pdf·절차·일정, 푸단대는 공식 2026 학부 안내 목록, 저장대는 공식 2026 지원 안내를 확인했다. HSK·영어·CSCA·서류·평가가 대학/전공/수업언어마다 다름을 명시하며 2028 확정 조건으로 표시하지 않는다.
- 칭화대 교내 학교장 추천 1명 및 면접 가능성은 사용자가 2026-10-29 직접 제공한 학교 안내이다. 대학 공통 규정이나 한국인 선발 정원으로 일반화하지 않는다. 교내 세부 선발 기준·일정은 담임 문의로 표시한다. 추천과 대학 최종 합격은 별개이다.
- 학생 개인 성적, 개별 학생에 대한 교사 메모, 확인되지 않은 점수별 학교 배정표를 공개하지 않는다.
