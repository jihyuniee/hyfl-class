# 숭실대 과거 정시 입결 원문 대조 (2026-10-30)

## 결론과 확인 범위

현재 수록된 숭실대 21개 모집단위 × 2024~2026학년도 = 63건을 공식 PDF와 대조했다. 수록 수치의 불일치는 0건이다. 전체 숭실대 학과·전형·연도별 모든 결과를 검증했다는 뜻은 아니다.

- 2026학년도 21건: 모집군·모집인원·경쟁률·충원인원·환산총점 평균·환산총점 70%·백분위 평균·백분위 70%의 8개 필드를 확인했다(168개 필드).
- 2024/2025학년도 42건: 추이표의 평균 백분위·경쟁률을 확인했다(84개 필드). 모집군·모집인원·컷·환산점수는 해당 추이표에 없으므로 null을 유지했다. 2026학년도의 값을 소급하지 않았다.
- 2026 환산만점 1000점은 별도 2026 시행계획 인쇄 28쪽과 일치한다. 다만 최종 모집요강과의 재대조는 완료하지 않았다. 통계표의 환산점수 수치 대조와 만점의 근거 확인 수준을 구분한다.
- 원래의 첨부 다운로드 주소는 여전히 조회 도구에서 `application/unknown` 오류를 반환했다. 공식 자료실이 제공하는 PDF 본문을 대신 열어 위 수록값을 대조했다. 두 파일의 바이너리 동일성은 확인하지 않았다.

## 출처와 학년도 구분

1. [공식 통계 게시물](https://iphak.ssu.ac.kr/board/statistics_view.asp?flag=2&keyword=&number=242&page=1&page_no=1_3_4&srchoption=): 제목은 2026학년도 입시결과 통계, 게시일은 2026-08-24이다.
2. [공식 전형안내책자 자료실](https://admission.ssu.ac.kr/board/file_4_list.asp?page_no=2_2_5)의 [2027학년도 입학전형 통계 PDF](https://admission.ssu.ac.kr/upload/SSU(1)_26051116627.pdf): 안내 대상은 2027학년도이며, 본문 목차와 결과 표의 대상은 2026학년도이다. 3개년 추이표에는 2024/2025/2026학년도 결과가 함께 있다. 자료실에 보이는 날짜는 2026-04-17로 통계 게시물의 날짜와 다르므로 파일 게시 이력을 하나로 단정하지 않는다.
3. 확인한 쪽수(인쇄 쪽수와 PDF 뷰어의 1부터 세는 페이지가 같음):
   - 28쪽: 2026 수능위주 정시 일반전형 인문·경상 모집군·인원·경쟁률·충원인원·환산총점 평균/70%.

4. [2026 시행계획 28쪽](https://admission.ssu.ac.kr/upload/2026_plan.pdf#page=28): 수능 일반전형 환산총점 1000점 명시. 이 문서는 시행계획이며 최종 모집요강을 대체하지 않는다.

## 반영한 변경

- 입결 숫자는 변경하지 않았다.
- 숭실대의 JSON/CSV 출처를 실제 본문을 연 공식 PDF로 연결하고 결과학년도에 따라 28쪽 또는 33쪽으로 이동하게 했다.
- 출처 설명에 결과학년도·책자 안내 대상학년도·정확한 쪽수·원래 통계 게시물·미기재 범위를 명시했다.
- 기존 출처 검사에 공식 `admission.ssu.ac.kr` 도메인을 허용했다.
- 공식 대조표 기반의 63건 회귀 검사, JSON/CSV 일치 검사, 출처 쪽수 검사를 추가했다.
- 화면의 기존 참고자료 안내와 검색 로직은 변경하지 않았다. ‘2024~2026 입결은 참고자료이며, 2028 합격을 보장하지 않아요’, 평균·컷·환산점수 구분, 자동 합격 판정을 하지 않는 원칙을 유지했다.

## 실행한 검사와 한계

작업 도중 명령 실행 환경이 중단되어 Node·npm·브라우저를 실행할 수 없었다. 아래 검사는 JavaScript 격리 실행 도구에서 수행했다. Node의 파일 읽기·assert·test·URL을 메모리 기반 대체 함수로 공급했고, 공유 TypeScript 모듈은 타입 주석을 제거하여 실행했다. 따라서 정식 `npm test` 실행 결과나 실제 브라우저 검사 결과로 표기하지 않는다.

- 기존 `admissions-seoul` 3개 + `admissions-browse` 7개 + 새 `admissions-ssu` 3개 테스트 본문: 13개 통과.
- 공식 수치 대조 252개 필드: 불일치 0개. 별도로 CSV/JSON 63건 일치 및 null 유지 확인.
- `SeoulAdmissions.tsx`에서 실제 `matchUniversity`와 `results.filter` 표현식을 추출해 수정된 데이터로 검색 8사례 실행: 모두 통과.

## 남은 항목

- 실행 환경 복구 후 정식 `npm test`, 타입 검사, 빌드 및 브라우저의 실제 필터 조작·PDF 링크 열기를 확인해야 한다.
- 2024/2025의 모집군·모집인원·70% 컷·환산점수는 이번 추이표에 없으므로 해당 연도 원문을 별도로 확인해야 한다. 2025/2026 안내용 통계 PDF는 조회 도구의 파일 크기 제한으로 열지 못했다. 빈칸은 확인 완료된 숫자나 0점이 아니다.
- 수록되지 않은 자연·자유전공 및 다른 전형을 포함한 숭실대 전체 결과와 2026 최종 모집요강의 만점·산식은 이번에 전수 검증하지 않았다.
- 원래 첨부 파일과 대체 공식 PDF의 파일 동일성·수정 이력은 확인하지 못했다.
- 상담표 XLSX의 입결 숫자는 이번 수록값과 동일한 상태로 유지했다. XLSX의 출처 설명을 새 PDF 쪽수로 갱신하는 작업과 파일 재검증은 하지 않았다.
