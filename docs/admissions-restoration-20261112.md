# 대입 탐색기 복구 — 2026-11-12

## 원인과 변경

PR #94에서 홈을 시행계획 외부 링크 하나로 바꾸고 `/admissions/seoul`, `/admissions/susi`, `/admissions/china`를 홈으로 리다이렉트했다. 기존 자료와 기능은 저장소에 남아 있었다.

- 리다이렉트를 제거하고 학급 주 메뉴·대입 공통 메뉴의 점수표, 계열별 학과, 정시 결과, 수능최저·면접 진입점을 복구했다.
- 홈에서 모의고사 표점합·평균 백분위를 바로 입력할 수 있다. PR #92의 502개 참고점수와 다섯 구간 규칙은 그대로 사용한다. 적용 시험·학년과 2028 적용성이 미확인인 자료라는 안내를 유지한다. 입결이나 확정 합격 예측으로 표시하지 않는다.
- 계열별 학과는 기존 공식 학과 안내 예시를 사용한다. 수시 화면에 계열 선택을 추가하고 실제 예시 학과명도 검색한다.
- 정시 결과는 11개 대학 292개 기록을 복구한다. 수록 범위는 2024학년도 109개, 2025학년도 162개, 2026학년도 21개(숭실대)이다. 대학 선택에 따라 학년도별 기록 수와 대학 수를 표시한다. `year` 검색 매개변수도 지원한다.
- 전형별 수능최저·면접·지원자격은 기존 공식·SEN 대조 기록만 표시한다. 충돌·미대조 기록 제외 규칙, 출처·쪽수, 시행계획 표기를 유지한다. 기존 시행계획 검색기 링크도 유지한다.
- 숫자 자료를 새로 생성하거나 기존 점수를 변경하지 않았다. 모든 대학의 최신 입결을 전수 갱신한 작업은 아니다.

## 확인

- 기존 Node 테스트 53개 통과. 점수 구간 경계와 502개 참고점수, 독립 원문 기준 292개 입결의 일치 검사를 포함한다.
- TypeScript와 변경 파일 ESLint 통과.
- Next.js 프로덕션 webpack 빌드 통과. 입시와 관계없는 Supabase 초기화를 위한 로컬 예제 환경값만 사용했다.
- 로컬 프로덕션 서버에서 대입 홈·정시·수시·중국 대학 경로의 HTTP 200과 각 페이지 제목을 확인했다. 정시·수시 경로는 홈으로 이동하지 않는다. 브라우저 조작은 배포 미리보기에서 확인한다.
