# 학급 60분 활용 점검 — 2026-10-29

## 확인한 범위
- 운영 브라우저: 한국외대 선택 → 정시 대학 필터 전달 → 가상 백분위 90/80/95/85, 영어 2등급 입력 → 단순 평균 86.67 및 외대 수록값 44건 표시 → 수시 화면의 대학 선택 유지 확인.
- 지원참고 예상점수 502건: 원자료 12개 JSON의 대학·학과·전형·모집군·표점합·백분위합과 전건 대조, 불일치 0건. 이는 원본 PDF나 현재 고2 적용성의 검증을 뜻하지 않는다.
- 학과 목록 472건, 실제 입결 292건(11개 대학), 2028 정시 반영사례 30건(15개 대학): 기존 회귀 테스트로 범위·중복·지표·분류 연결 확인.
- 한국외대 공식 2028 시행계획 PDF를 새로 내려받아 본문 10쪽의 서류형 서울 2합6/글로벌 2합7, 본문 14쪽 정시 A 30/20/20/30 및 B 20/30/20/30, 탐구 상위 1과목, 영어 200/198/194와 데이터 일치 확인.
- 숭실대 원문 게시물의 결과 학년도 2026, 게시일 2026.8.24와 첨부 제목 2027 입학전형 통계를 구분해 재확인. PDF 본문 재다운로드는 연결 오류로 실패하여 숫자 전건의 신규 원문 대조는 완료하지 못했다.
- 서울대 공식 검색 결과에서 2026.9.23 예시 문항 게시물 및 2028 수시 일반전형 안내 영상의 적용 범위를 재확인. PDF 개별 문항은 미검토.

## 수정
- 첫 화면에 참고자료의 역할·수록 범위와 접어 볼 수 있는 60분 활동 예시 추가. 학생에게 대학·전형·진로 확정을 요구하지 않는다.
- 수시·정시 선택과 탐구 안내의 단정적 표현을 비교·참고 질문으로 수정.
- 지원참고 출처에 원래 ‘고1 가채점’ 표기가 있음을 공개하고 원본 시험일·대상 및 현재 고2 적용성이 재확인 중임을 표시. 모의고사 입력 결과를 수록값 비교로 명명하고 영어가 검색 순서에 반영되지 않음을 명시.
- 학교를 먼저 선택한 뒤 계열 버튼을 누를 때 대학 선택이 초기화되는 문제 수정.

## 남은 한계
- 전체 입결 292건·정시 반영 30건·수시 전형 전체를 이번에 외부 원문과 전건 재대조한 것은 아니다.
- 학교별 원문 링크/사본의 접근성과 변경 사항은 다를 수 있다.
- 원본 지원참고표 시험정보 재확인 전에는 현재 학생의 지원 가능성 예측으로 해석할 수 없다.
- 브라우저는 기본 뷰포트에서 확인했으며 실제 휴대전화 크기에서의 전수 시각 검증은 미완료.

## 후속 확인 — 2026-10-30

숭실대 수록 21개 모집단위·63건은 공식 자료실의 PDF 본문과 후속 대조했으며 수록 수치 불일치는 없었다. 원래 첨부 파일 자체의 재다운로드·파일 동일성 확인 및 정식 npm/브라우저 검사는 완료하지 못했다. 확인한 필드·쪽수와 남은 항목은 [숭실대 후속 점검](admissions-ssu-audit-20261030.md)을 따른다. 위 기록은 2026-10-29 당시의 확인 범위로 보존한다.
